# Library Management System

A simple Library Management System built with HTML, CSS, and TypeScript.

## Features

- Display books as cards
- Search books by title or author
- Filter books by category
- Show total and available books
- Change book availability
- Remove books
- Add new books
- Upload book images
- Add regular books and reference books

## Technologies

- HTML
- CSS
- TypeScript
- Object-Oriented Programming (OOP)
 

## Project Structure

- index.html - Main HTML page
- Book.ts - Book class
- ReferenceBook.ts - Reference book class
- Library.ts - Library management class
- assets/ - CSS, JavaScript and images

## How to Run

1. Open the project in VS Code.
2. Compile the TypeScript files.
3. Open index.html using Live Server.

## Main Features

The application allows users to:

- Search for books.
- Filter books by category.
- Add new books.
- Add reference books.
- Change book availability.
